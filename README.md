Je ne l'ai plus lâché.

J'ai d'abord remplacé la carte en papier par des cartes à puce. Puis j'ai construit MAGBO Access Control, qui tourne en production depuis juillet 2026.

Aujourd'hui, je m'installe à Bordeaux et je cherche un CDI de développeur backend Java / Spring Boot junior.
